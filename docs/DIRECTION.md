# 木漏れ日 / 独立街角样片

## 第十三轮：去除多余陈设、明确雨具用途

删除右墙收音机、天线、旋钮与仅承接它的搁板及支架，不用新摆件填补空位。入口弃用锥形封闭伞筒，改为窄深度的石墨绿 #3b4640 开放钢架、浅灰 #969f97 可抽出接水盘和少量黄铜 #ad9875 接头，延续胡桃木与绿布背景。三个独立伞位保留一个空位，两把收拢伞错落放入；框架、分隔和滴水承接形成可读的使用关系，而不是给垃圾桶换材质。

## 第十二轮：可读的咖啡菜单与可辨识的雨具

延续胡桃木、卡座绿、石墨和瓷白，不新增主题装饰或灯光。“本日の珈琲”保留原板尺寸和明朝体，八款咖啡分为豆种手冲与奶咖/冷萃两栏，名称左齐、价格右齐，避免为塞文字横向压缩字体。入口雨伞筒保持原位与尺度，三把伞补收拢的褶皱伞面、束带、伞尖和弯柄，让它读起来是日常雨具而非抽象细杆。

## 第十一轮：营业动线、真实接触与有出处的光

继续使用胡桃木 #82634c、卡座绿 #405e50、器械石墨 #303e42、拉丝钢 #bec8c7、瓷白 #eee4d1，明朝体招牌与小号无衬线器械文字不变。这轮不增加主题装饰：卡座桌椅整体移向正面窗户，让出吧椅后方；收银与托盘交付在蛋糕柜右边，浓缩区集中磨豆/压粉/敲渣，手冲转到后方热水备料台。

反思：上轮只检查了若干成对物件，漏掉了布面经过倒角时的细分折线、整组座位包围范围以及豆仓内部的体积关系；通过断言不等于营业空间已经合理。毛巾按台沿圆角形成连续曲面，咖啡豆由漏斗内的连续豆床承接；墙角采用封闭直角和真实木收口。删除空中补光点，保留日光/天空与实体吊灯，工作补光来自有轨道、筒身和镜片的灯具，柜下光来自已有灯条，不用墙面亮斑冒充灯具。

## 第十轮：相邻出品区与器械净距

蛋糕柜放到吧台左端，面向顾客且不占入口至墙边书柜的通道；柜体、糕点、灯条、接触阴影和取景一起移动。门右侧菜单架绕自身中心转向入口，不倾斜支脚或再次占用踏步。

延续胡桃木 #82634c、石墨 #303e42、拉丝钢 #bec8c7、瓷白 #eee4d1 与绿釉 #496659，明朝体菜单和小号器械屏幕不变。交付杯、菜单与收银屏组成靠顾客侧的小组，磨豆、压粉和浓缩机保留在操作侧。修复旋钮、表盘、蒸汽臂、出水嘴、杯碟和器具底座的具体相交，不靠减少细节、隐藏设备或改镜头避开问题。

## 第九轮：门前通行

菜单立板整体移到门右侧窗下，保留可阅读朝向，避开踏步、绿植和路缘；删除误放到柏油车道的矮凳及其手袋，不再以无使用情境的陈设占用道路。

## 第八轮：真实支撑、限定光域、营业中的喫茶吧台

- 保留胡桃木 #82634c、绿布 #405e50、瓷白 #eee6d5，器械采用石墨 #303e42 / 拉丝钢 #bec8c7，入口绿植用深叶 #4e7555 与灰绿 #849779。
- 字体维持店牌明朝体、器械小号无衬线；不增加无功能标语，不把触控面板画成整面发光广告。
- 先消除铺装共面、重复柜框与玻璃排序，再处理灯的室内空间遮罩；保留日光、花冠分级和 MSAA，不通过降精度掩盖闪烁。
- 吧台以大型三头商用机为主角，双磨豆机、压粉/冲洗/出杯形成工作组，后吧台安排过滤水塔、备料器皿和清洗收纳；保持真实操作通道。
- 吊灯改成有吊盘、灯座、厚边罩和乳白灯泡的绿釉/黄铜灯具；入口以枝叶相连的山茶、蕨与小叶灌木错落成组，避开门、停车架与人行通道。

复核：不沿台面等距复制小物，不整机等比放大旧家用模型；设备的体积、内部层次、通风、操作面与管路重新设计。空间遮罩是低成本定向近似，不冒充全局光照或物理墙体遮挡。

## 边界

本次从空目录独立写几何、布局、纹理、树冠与交互，不导入或复制原样例及上一版本的建模代码。仅使用 npm Three.js 与其官方几何合并/控制器。先验收一个街角，不把样片称为完整小镇或宣布超过参考。

## 设计计划

主角是一间坡道转角的木质喫茶店，沿左侧窄巷看到远处铁路。没有复制参考的直街对称构图。

- 色板：纸白 #E6DED0，屋瓦青 #526F79，柚木 #76523F，春花 #F2C0CE，天空 #A9CFDE，背阴 #69748C。
- 字体：场内手绘日文店牌与菜单；网页仅系统明朝体站名和小号黑体操作提示。
- 构图：三分之二视角看店面和侧墙，左边坡道留下远景空隙；近处花枝框住屋檐，前景自行车和排水渠提供人尺度。
- 细部：真实窗洞、结构梁、瓦片边缘、铜雨槽、门把手、踏步、螺丝、接缝、布帘、店内吧台和器物，而不是在盒子正面贴字。
- 树冠：弯曲锥形枝条、多层分散花枝、杯状实体五瓣花、近景缺口和花蕊；避免粉色球和大片相交花片。花枝方向和颜色有小幅变化，不靠照相机朝向的卡片支撑体积。
- 负载：共享几何/材质、静态合并、花枝实例化与按像素尺寸分级、稀疏但保留曲面的倒角；保留 MSAA。阴影使用固定花冠几何，镜头分级与阴影解耦；记录实际像素、阴影和样本数，不用卡片版帧率冒充实体版优化成绩。

## 复核

删掉大标题和路线面板。空间和美术是主角，界面只是取景工具。不是重新给参考换名字，新的房屋轮廓、树形、道路方向与镜头均独立确定。

## 验收

街角全景、屋檐/店面近景、室内三个机位；实测绘制次数与帧率，保留截图和限制说明。样片通过后才扩展小镇。

## 第三轮方向：街角喫茶与窗光

不把“日系”理解为堆满日文字和灯笼。采用近郊旧喫茶店的深木吧台、分区瓷器柜、绒绿卡座、琥珀/乳白拼色吊灯、蕾丝短帘和少量音乐收藏；保持入口到吧台的动线，窗边有正在使用的杯碟而不是对称复制摆件。

- 色板：胡桃木 #624432、卡座绿 #405E50、旧黄铜 #AE8C53、乳白瓷 #EEE2CC、窗光蓝 #CADCE4、玻璃琥珀 #C9A55D。
- 字体：明朝体店牌、手写感菜单；文字尺寸按实体比例确定，不通过横向拉伸适配。
- 空间：后方器具柜 → 吧台操作区 → 不完全等距吧椅；右侧卡座与窗边双人桌分开，保留中间通道。
- 光线：降低室内天空漫反射泄漏；来自窗口的冷色柔光与定向日光，局部吊灯暖光。灯光本身塑造层次，不靠全屏黄色滤镜。阴影缓存，不引入每帧反射捕捉或全局光照计算。
- 停车：小店使用两位前轮轮槽固定架，轮胎实际位于槽内，底座锚固、空位和“お客様専用”牌可见。不使用车站规模的收费闸机。
- 花冠：把一部分末梢花量重新分配到主枝过渡处，减少分离球簇，保持实体花瓣。分级加入滞回，不用继续堆数量掩盖轮廓问题。
- 负载：保持抗锯齿与全部花量；花冠只计算天空和日光，不接受店内点光/聚光。空间遮罩在片元内复用，避免每盏灯重复判断室内边界。

复核：舍弃“统一浅木桌椅+整齐瓶子”这种普通咖啡店默认布景；旧喫茶的特点由座位、工作区、灯罩和材料共同表达，而不是依赖装饰文字。

## 第四轮方向：可读的器物与有来源的花

- 壁画：保留可编辑 Canvas 画稿，不再用几根抽象线代表完整作品。枯山水采用砂纹、石组、苔岛和淡墨远墙；咖啡静物采用窗边光、瓷杯、手冲壶、羊角包、花瓶与棉麻。石灰白 #DDD8C7、苔绿 #667663、岩灰 #777870、咖啡棕 #654735、瓷白 #EFE7D5；实体双层画框与卡纸保持纹理比例。
- 书籍：封面、书脊、纸页分层，厚薄/开本变化，几本倚靠、几本平放和一本摊开的读物；书籍必须由搁板支撑，不用整体随机旋转制造浮空。
- 吧台：从简单盒子重做双头咖啡机、磨豆机、虹吸与手冲区；结构体现冲煮头、手柄、蒸汽管、接水盘、压力表、豆仓、液面和滤纸，而非靠文字命名。
- 樱花：花枝挂在实际骨架上，花朵放在细枝采样点并有花梗。飘落出生点来自真实花朵变换，不使用统一高空平面；风偏移从零开始，下降不超过出生高度。
- 负载：细枝低段数合并、花梗共用实例几何、仅 220 片飘落更新；保留三级花冠分级与 MSAA，记录新的几何和实测负载，不隐瞒附着结构的成本。

复核：两幅画用不同的题材、笔触和空间关系，而非换一行标题；花枝连接与物件支撑是本轮的质量底线。

## 第五轮方向：屋顶承接与现代工作区

- 花瓣：对建筑实际屋瓦、屋面、玻璃和墙面预计算下降路径的首次接触，落在接触表面并按法线平躺。地面散瓣也先查询屋顶，避免在室内地板生成；不以隐藏全部落瓣规避问题，不在每帧遍历建筑三角形。
- 书架：移除中间矮架，在左后方实墙旁放置约 1.9 米高的窄深胡桃木书柜，面对店内，保留柜侧至吧台的通道；书籍混合立放、倚靠和堆叠，书柜不能挡住窗洞。
- 蛋糕：六个位置分别为草莓奶油切片、莓果塔、歌剧院蛋糕、巴斯克芝士、抹茶千层、栗子蒙布朗，轮廓、层次和装饰各异，价格卡对应品种而非循环换色。
- 仪器：保留旧喫茶空间，在工作区引入低矮双头现代咖啡机，石墨黑 #303D40、不锈钢 #BEC8C7、数字屏蓝 #A8CBD1、陶瓷白 #ECE4D2；电子温压/计时屏、背光按键、独立冲煮头、现代称重磨豆机与温控壶。旧虹吸展示减少到一组，台面区分浓缩与手冲工作流程。

复核：现代化集中在设备形体与控制方式，不给整个老店套科技风；书柜是靠墙家具，不是中央展示台。落瓣碰撞使用真实模型表面，不用屋顶高度硬编码。

## 第六轮方向：路权、阅读陈列与咖啡工作流

- 室外：道路与标线统一为纵向车道，近处左树移到路缘外的独立种植带，补土壤、树池和路缘；后方窄人行道的树移入店后花园，五株树位与种植位共用配置，检查树干净距而不是只挪镜头。
- 书柜：底层大开本收藏、第二层错落堆叠与短排立书、第三层封面展示与旅读、顶层小书与陶瓶，四层各自构图，改变搁板间距；纸页由搁板或书挡支撑，不靠随机旋转。
- 光线：重建白天喫茶的冷暖分层，降低原室内遮罩的压暗程度，增加有方向的窗口填充和中性暖色工作照明；搁板灯带与吊灯分别照明，不靠全屏曝光洗白。保留窗影、深木与绿色卡座。
- 工作区：后柜与前吧台分开，后方洗涤/备料、前方手冲/交付与浓缩区，保证约 0.9 米操作通道；嵌入水槽/龙头、冷藏下柜、抽屉、轨道杯架、杯碟和豆罐按工作区分类。菜单留独立中央墙面，左右搁板不得跨越菜单。
- 色板：胡桃木 #71503C、不锈钢 #B9C6C5、乳白瓷 #F0E8D9、深绿 #405E50、中性暖光 #FFF1DB、窗光 #D6E5EC。标题使用明朝体，功能标注使用易读黑体；不用大规模英文或日文贴牌代替结构。

复核：去掉贯穿菜单的整墙格柜和等距十瓶陈列，采用左右分区、有工作台和真实使用关系的后吧台；增加的是专业结构而不是随机堆小物件。灯光的目标是可读的室内层次，而非失去明暗。

## 第七轮局部修正：连续柏油路与明确步道

- 门前及左侧车道统一为连续柏油面 #777E87，材质颗粒按世界尺寸重复，不用另一块浅色地台遮盖道路。
- 浅灰步道 #B4B5A7 只围绕店面形成 L 形，路缘 #A9AAA0 与排水沟终止于转角，停车架高度和承接地面保持不变。
- 移除没有清楚表达功能、而且放在车道里的简化凸面镜；不替换成新的无用路牌，不改室内、树位或灯光。

复核：这轮做减法，修正路面范围和交界，不靠新增装饰遮住错误。
